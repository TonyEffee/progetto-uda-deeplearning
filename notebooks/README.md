# Jupyter Notebooks

`UDA_Colab_Training.ipynb` documenta l'esecuzione degli esperimenti su Google Colab con GPU T4:
setup dell'ambiente, lancio degli script di training e valutazione, e salvataggio dei risultati su Drive.

Il notebook non contiene logica di training: si limita a invocare gli script in `src/`.
Gli output delle celle sono quelli delle esecuzioni reali.

GitHub potrebbe non riuscire a visualizzare il file per via della dimensione degli output:
in tal caso, scaricarlo e aprirlo in Colab o Jupyter.
